# Experiment 7: Familiarization and Usage of Collaborative Applications (SaaS)

## 📌 Aim

To become familiar with Software as a Service (SaaS) and perform basic collaborative activities using cloud-based productivity and communication applications.

## 🛠️ Technologies and Tools Used

- **Google Docs:** Cloud-based document creation and collaboration.
- **Google Sheets:** Online spreadsheet creation and data management.
- **Google Slides:** Cloud-based presentation creation.
- **Google Meet:** Online video conferencing and communication.
- **Microsoft 365:** Cloud-based productivity applications.
- **Microsoft Teams:** Online communication and team collaboration.
- **Web Browser:** Accessing cloud-based SaaS applications.

## 📚 Experiment Overview

This experiment is divided into four major practical tasks.

### Task 1: Introduction to SaaS and Collaborative Applications

**Objective:** Understand the concept of Software as a Service and explore cloud-based applications.

**Topics Explored:**
- Meaning of Software as a Service (SaaS).
- Cloud-based application access.
- User authentication and account management.
- Cloud storage and file sharing.
- Real-time collaboration.
- Version history and activity tracking.
- Application settings and access permissions.

**Examples of SaaS Applications:**
- Google Docs
- Google Sheets
- Google Slides
- Microsoft 365
- Microsoft Teams
- Zoom
- Dropbox
- Salesforce

**Key Features of SaaS:**
1. Applications are accessible through the internet.
2. Software updates are managed by the service provider.
3. Data is stored in cloud infrastructure.
4. Multiple users can collaborate in real time.
5. Applications can be accessed from multiple devices.

### Task 2: Collaborative Document Creation Using Google Docs

**Objective:** Create, edit and share an online document with multiple users.

**Steps Performed:**

1. Opened Google Docs using a web browser.
2. Signed in using an authorized Google account.
3. Created a new blank document.
4. Named the document **Cloud Computing Lab 7 – Collaborative Document**.
5. Added information about Software as a Service.
6. Created a table describing different SaaS features.
7. Shared the document with a collaborator.
8. Assigned appropriate access permissions.
9. Performed collaborative editing and commenting.
10. Explored document version history.

**Sample Document Content:**

**Title: Software as a Service**

SaaS is a cloud service model in which software applications are delivered to users through the internet. Users can access applications without managing the underlying infrastructure.

| SaaS Feature | Description |
|---|---|
| Accessibility | Applications can be accessed through the internet. |
| Collaboration | Multiple users can work on shared content. |
| Updates | Software updates are managed by the provider. |
| Storage | Data can be stored in the cloud. |

**Collaboration Features Explored:**
- Document sharing.
- Viewer, Commenter and Editor permissions.
- Real-time editing.
- Adding comments.
- Version history.

## ⚠️ Precautions

1. Use authorized Google or Microsoft accounts.
2. Do not share account passwords with others.
3. Share documents only with authorized collaborators.
4. Assign appropriate Viewer, Commenter or Editor permissions.
5. Avoid sharing confidential information publicly.
6. Verify document and spreadsheet sharing settings.
7. Maintain proper organization of cloud-based files.
8. Check changes before restoring previous versions.
9. Use a stable internet connection during collaborative activities.
